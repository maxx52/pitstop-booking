# Питстоп

Демонстрационная онлайн-запись в автосервис. Клиент выбирает услугу и свободное время, администратор подтверждает, переносит или отменяет заявки, а также меняет рабочие часы на выбранную дату.

## Локальный запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Клиентская запись открывается по адресу `http://127.0.0.1:5173/`, календарь — по адресу `http://127.0.0.1:5173/admin`. Локальная база создаётся в файле `.pitstop.sqlite`. Для проверки API выполните `npm test`. Команда `npm run build` собирает Vue-интерфейс и Worker для размещения с D1.

В демо используется один сервисный пост, часовой пояс Новосибирска, горизонт записи 30 дней и шаг расписания 30 минут. Проверка занятости и запись выполняются одной SQL-командой. Отменённые заявки освобождают время. Доступ к демонстрационной админке открыт всем посетителям экземпляра. Используйте вымышленные имена и автомобили.
